Supplier Onboarding Agent · presenter guide

Demo recording script

Everything you need to record the 3-minute demo video: what to set up, then for every scene what to click, what to point at, and what to say.

Length: about 3:00 Opening: 30 s on the problemScenes: 8 clicks Cost per run: $0 (saved answers) Rehearse: as many times as you like

Before you record

  1. Open http://localhost:8000 in your browser. If the page doesn't load, open Terminal in the project folder and run: 
    .venv/bin/uvicorn app.main:app --port 8000
  2. Make the browser full screen. If the page doesn't fit, zoom out to 90% with Cmd + −.
  3. Do one full practice run, then click Start over.
  4. Start the screen recorder. QuickTime: File → New Screen Recording, then choose to record the browser window.

Tips

Wait for the green buttonWhile it says “Please wait…”, the agent is still working. Each scene takes a few seconds.
Rehearse freelyClick Start over any time. Every run uses saved answers and costs nothing.
Keep the orderUse only the green button during the recording, not the “Manual controls”. The saved answers rely on the scenes running in order.
Recording in parts?Don't click Start over between parts. Just continue with the next green button.
Speed it up laterIn editing, speed up the waits between clicks 2–4× so the whole video stays under 3:00.

If something goes wrong

What you seeWhat to do
The page doesn't loadThe app isn't running. Start it with the Terminal command in “Before you record”.
The button stays on “Please wait…” for more than 20 secondsRefresh the page (Cmd + R), click Start over, and run the scenes again from the start.
“Something went wrong” appears under the buttonA scene was run out of order. Click Start over and use only the green button.
Terminal says “address already in use”The app is already running. Just open http://localhost:8000.
