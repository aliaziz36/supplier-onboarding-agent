The Seal · presenter guide

Demo recording script

Everything you need to record the 3-minute video: setup, the keys, and for every step what to press, what to point at, and what to say.

Length: about 3:00 Opening: 45 s storySteps: 9 Cost per run: $0 (replay of recorded runs) Rehearse: as many times as you like

Before you record

  1. Make sure The Seal is running in replay mode. If http://localhost:8000 doesn't load, open Terminal in the project folder and run: 
    REPLAY=1 ANTHROPIC_API_KEY= .venv/bin/uvicorn app.main:app --port 8000
  2. Open http://localhost:8000/dashboard, make the browser full screen, and press R to start over. The inbox should be empty.
  3. Rehearse once with the narration showing: press H to show it, read along, press R at the end. Press H again to hide it. While it's hidden, nothing presenter-related is on screen.
  4. Go to http://localhost:8000 (the start page) for the opening, and start the screen recorder. QuickTime: File → New Screen Recording.

The keys

N or →Next event: the next email arrives, or the next step happens.
BBack one step (replays everything up to the step before).
RStart over with an empty inbox.
HShow or hide the narration panel. Keep it hidden while recording.

The run

Tips

Wait for “Agent idle”Each email takes 5 to 15 seconds to play out. The sidebar shows “Agent working” until it's done; then press N.
Rehearse freelyPress R any time. Every run replays recorded answers and costs nothing.
Keep the orderUse N to move forward. The recorded answers rely on the emails arriving in this order.
Recording in parts?Don't press R between parts. Continue with N; B goes back one step for a retake.
Speed it up laterIn editing, speed up the waits 2–4× so the video stays under 3:00.
Don't press “Process a new email”It calls the paid API. While the app runs without a key it only shows a message.

If something goes wrong

What you seeWhat to do
The page doesn't loadThe app isn't running. Start it with the Terminal command in “Before you record”.
“Agent working” for more than 20 secondsRefresh the page (Cmd + R). If it still looks stuck, press R and run from the start.
“Something went wrong” in the activityA step ran out of order. Press R and use only N.
Pressing N does nothingClick once on an empty part of the page so it has keyboard focus, then press N again.
Terminal says “address already in use”The app is already running. Just open http://localhost:8000/dashboard.
